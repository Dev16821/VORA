# VORA

VORA is an offline Linux desktop AI assistant prototype.

## Version
v0.1 - Backend prototype

## Current Features
- Basic command routing
- System command handling
- Website opening
- App opening
- Local Ollama / Llama integration structure
- Memory cleaner utility

## Status
This is an early backend-only prototype. Character design, UI overlay, animations, and deeper Linux integration will be added in future versions.
